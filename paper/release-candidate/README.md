# SAT-SA: IEEE Access submission package

This is the upload package for *Record-Level Supervisory Analytics for Security
Operations Centres: Controlled Evaluation, Cryptographic Decision Binding, and an
External Negative Result*. The target is IEEE Access, article type Applied Research.
It is generated by `python paper/make_submission.py` from the repository's `paper/`
directory. Do not edit files here by hand: edit `paper/` and regenerate.

**Status: not ready to upload.** Author information, biographies, confirmation of
the AI-use disclosure, and a public copy of the code are PENDING. See
`../VENUE_COMPLIANCE.md`.

## How the results were generated

1. Each experiment ran from a committed source tree and wrote a write-once bundle
   (manifest, configuration, raw results, metrics, summary) with SHA-256 hashes.
2. The canonical bundles were frozen as `research/evidence/freeze-v2`. Its
   `freeze.json` has SHA-256
   `2ac93ef3f2967f908c35b05c1fed97dc60282aa503d1a97594275deae3a1ff0a`.
3. `scripts/build_paper_assets.py` verifies the freeze and renders every value,
   table and figure from it. `scripts/audit_paper.py` regenerates them and checks
   that the files are byte-identical. It also rejects undefined macros and
   hand-typed decimals, checks every citation against the verified matrix, and
   scans for prohibited claim wording.

## Data

- **Synthetic (controlled):** the controlled catalog, the generated populations
  (seeds 100–119, 300–304) and the engineered peer cohorts. They regenerate from
  the seeds and configurations in S1.
- **External:** UCI Machine Learning Repository dataset 498, *Incident management
  process enriched event log* (Amaral, Fantinato, Peres, 2018;
  doi:10.24432/C57S4H; CC BY 4.0). It is real IT service-desk data, not SOC data,
  and it is **not redistributed**. The runner downloads it and verifies CSV
  SHA-256 `fd184bbfd62329cfe093e99da2ea7071905f2ead91900b448eb2635870821bef`.
- No personal data, no real SOC data and no human-participant data were used.

## Verify and reproduce (from the repository root)

```powershell
python scripts/verify_evidence_freeze.py research/evidence/freeze-v2   # Level 1
python scripts/build_paper_assets.py                                  # Level 2
python scripts/audit_paper.py                                         # Level 2 audit
python paper/make_submission.py
python scripts/audit_paper.py --paper paper/submission                # audit this package
cd paper/submission; pdflatex manuscript; bibtex manuscript; pdflatex manuscript; pdflatex manuscript
```

## What cannot be reproduced, and why

- **Bit-identical bundles:** timestamps, run ids, keys and ML-DSA signatures
  differ by design.
- **Timings:** they depend on hardware and load.
- **PostgreSQL, SeaweedFS/S3, containers, CI topology and hosted deployment:** these
  were never executed, and no reported number depends on them.
- **Human study and expert labels:** none exist.
- **Literature-search counts:** they drift as the indexes change. The raw
  responses of 2026-09-27 are kept in the repository.
