# Springer LaTeX2e Proceedings Template (vendored)

These files come unmodified from the official Springer "LaTeX2e Proceedings Template (ZIP)":

- **Source:** linked from "Downloadable instructions and templates" at
  https://link.springer.com/series/558/information-for-authors-and-editors
  (retrieved 2026-09-27).
- **ZIP SHA-256:** `42afb32ed4fadc9e209134ec65dab1bd2a7ead42f9a3f8abb184f250c4a197b9`.
- **Class:** `llncs.cls`, version 2.25 (2026-09-03).
- **Bibliography style:** `splncs04.bst`.

Springer states that the template applies to its Computer Science proceedings series
(LNCS, LNAI, LNBI, CCIS, LNBIP, LNICST, IFIP AICT). The reference paper supplied by
the author (a Lecture Notes in Electrical Engineering chapter) uses the same
single-column Springer proceedings layout.

The sample paper and the example figure are omitted. `paper/build_overleaf.py`
copies these files into the Overleaf package.
