# IEEE Access LaTeX template (vendored)

These are the class, bibliography style, style and font files from the official IEEE
Access LaTeX template, which the submission build needs to compile.

- **Source:** https://ieeeaccess.ieee.org/wp-content/uploads/2026/05/ACCESS_latex_template_20260513-1-1.zip,
  linked from https://ieeeaccess.ieee.org/authors/preparing-your-article/.
- **Downloaded:** 2026-09-27.
- **ZIP SHA-256:** `60c7efc9db8ac9e8bdb31c550ad4e03cb6f258a878ececc0bc690b6203e45a67`.
- **Omitted from the ZIP:** the example `access.tex`, its build outputs and the
  example images (`author*.png`, `fig1.png`, `equation3.png`).

The files are not modified. `paper/make_submission.py` copies them into
`paper/submission/`.
