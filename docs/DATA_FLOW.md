# Data Flow Diagram Description\n\nThe platform processes data through a deterministic pipeline:\n\n1. **Data Ingestion** – `mlops.DataPipeline.run` consumes raw sources.\n2. **Validation** – agents in `qsmlops.agents` emit validation observations captured by the supervisor.\n3. **Feature Engineering** – part of the data pipeline (future implementation).\n4. **Training** – `mlops.TrainingRequest` triggers a `TrainingJob`; results stored as artifacts.\n5. **Evaluation** – `mlops.EvaluationReport` produced and attached to the model passport.\n6. **Packaging** – `mlops.PackageInfo` bundles model artifacts and metadata.\n7. **Registry** – `ModelRegistry` records version metadata and hashes.\n8. **Deployment** – `mlops.DeploymentRequest` creates a deployment record; `ModelDeploymentService` loads and serves the model.\n9. **Monitoring** – runtime metrics streamed to `monitoring` components.\n\nEach step emits events on the `EventBus` (e.g., `ModelCreated`, `TrainingCompleted`) enabling asynchronous observers such as audit logs, dashboards and security checks.\n
