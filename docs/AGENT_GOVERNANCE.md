# Agent Governance\n\nAgents are **intelligent observers** that never act autonomously. Their lifecycle is governed by the Adaptive Supervisor.\n\n## Core Principles\n* **Evidence‑Based** – agents produce `Observation` objects that contain findings and a recommended action.\n* **Least Privilege** – each agent is registered with a limited `CapabilitySet` and a `PermissionSet` defined in `agents/capabilities.py` and `identity/permissions.py`.\n* **Review Loop** – the supervisor evaluates all evidence, applies policy rules and decides whether to ACCEPT, ESCALATE or trigger mitigation actions.\n\n## Adding a New Agent\n1. Subclass `qsmlops.agents.base.BaseAgent` and implement `observe(context)`.\n2. Declare capabilities in `agents/capabilities.py`.\n3. Register the agent with `agents.registry.AgentRegistry`.\n4. Optionally add permission checks in `identity.service.IdentityService`.\n\nAll agents automatically participate in the workflow engine through the supervisor's `run_cycle` method.\n
