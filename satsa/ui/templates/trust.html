02 / Technical details

How the integrity layer works

AlgorithmML-DSA-65 (NIST FIPS 204) via dilithium-py pure-Python implementation
DigestSHA3-256 over the canonical JSON of the record (sort_keys, ensure_ascii=False, no whitespace, no NaN)
Key storageLocal JSON keystore at {{ trust_key_dir or 'unconfigured' }}; restricted to owner-only on POSIX
Hardware supportHonest disclosure: no PKCS#11 token on Earth supports ML-DSA yet — the platform fails closed and self-certifies this
LedgerAppend-only hash-chained evidence ledger; verification walks every prior digest and confirms the chain head
Trust claimDetection of tampering at verification time, not tamper-proofness — see docs/TRUST_MODEL.md
